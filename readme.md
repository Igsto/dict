# Словарь для изучения анлгийского

Приложение для повторения и добавления слов на PyQt6 + SQLite

## Возможности

- Добавление слов с четырьмя вариантами перевода
- Игра угадай слово
- Сохранение в локальную БД

## Описание игры
Выпадает загаданное слово, необходимо угадать правильный 
вариант перевода. Если получилось угадать - вокруг рамки зелёный
цвет, нет - красный, правильный вариант подсвечивается зелёным

## Запуск
pip install -r requirements.txt
python -m dict
